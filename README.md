# Iris Flower Classification

A beginner-level Machine Learning project that predicts Iris flower species using a Decision Tree Classifier.

## Problem Statement
Classify Iris flowers into Setosa, Versicolor, or Virginica using four measurements:
- Sepal length
- Sepal width
- Petal length
- Petal width

## Tech Stack
- Python
- Pandas
- Seaborn
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Workflow
1. Data loading and exploration
2. Exploratory Data Analysis (EDA)
3. Data preparation
4. Train-test split
5. Decision Tree model training
6. Model evaluation

## Results
- Algorithm: Decision Tree Classifier
- Training samples: 120
- Testing samples: 30
- Accuracy: 96.7%

## Files
- `iris_classifier.ipynb` — Jupyter Notebook containing the project code.
- `iris_project_report.md` — Detailed project report.
